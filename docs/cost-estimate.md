# API 비용 참고 — 2026-09-07 확인

2026-09-07에 조회한 단가를 사용한 계획용 참고 자료입니다. 이후 API 키 설정과 연결 확인은 완료했지만 이 문서의 계산에는 연결 확인 비용과 실제 청구 내역을 반영하지 않았습니다. 파일럿 후 실제 토큰 수와 당시 단가로 다시 계산합니다.

## 무료 API

- Groq API: 무료 요금제와 모델별 호출 한도가 있습니다. https://console.groq.com/docs/rate-limits

무료 제공처는 참고만 했으며 무료 API를 실험에 연결하거나 사용하지 않았습니다.

## 유료 비용 예시

- 모델당 180회 = 도구 12개 × 조건 3개 × 고정 요청문 × 반복 5회.
- 시행당 모델 호출 1회.
- 입력 1,000~3,000토큰, 추론 토큰을 포함한 과금 출력 300~1,000토큰을 가정.
- 표준 유료 단가 기준. 무료 할당량·캐시·배치 할인은 반영하지 않음.
- 달러 금액은 세금·결제 수수료 제외.

| 모델 예시 | 입력 $/백만 토큰 | 출력 $/백만 토큰 | 180회 비용 |
|---|---:|---:|---:|
| GPT-5.6 Sol | 4 | 20 | $1.80~5.76 |
| Claude Sonnet 5 | 2 | 10 | $0.90~2.88 |
| 합계 | | | 약 $2.70~8.64 |

계산식: 180 × (입력토큰 × 입력단가 + 과금출력토큰 × 출력단가) / 1,000,000.

환산용 $1=1,500원 가정 시 합계 약 0.4만~1.3만 원입니다. 이 환산값은 실제 환율 조회값이 아닙니다. 파일럿과 제한 재시도를 포함한 준비 예산은 약 1만~3만 원으로 잡을 수 있습니다. 긴 추론, 모델 단가 변경, 재시도 증가 시 비용도 증가하므로 파일럿의 실제 토큰 사용량으로 다시 계산해야 합니다.
